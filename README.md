# Minecraft AI Bot

V1 Minecraft bot built with Node.js, Mineflayer and mineflayer-pathfinder.

## Setup

1. Install Node.js 18+.
2. Run `npm install`.
3. Edit `config.json` with your server address, port and bot name.
4. Run `npm start`.

## Chat commands

- `!help` - show commands
- `!pos` - show bot position
- `!come` - follow the player who issued the command
- `!stop` - stop pathfinding

The bot automatically reconnects after disconnecting.
