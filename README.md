# CloudGaming

Android Windows 10 virtual machine project powered by a QEMU-based backend.

## V1

The project is designed as an Android frontend for a local Windows VM, with VM configuration, lifecycle controls, storage management and a future display/input layer.

Windows installation media is not included. Use your own legally obtained Windows ISO and license.

## Build

Open the Android project in Android Studio, sync Gradle and build the `app` module.
